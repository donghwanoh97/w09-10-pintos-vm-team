테스트가 실패했고 원인 파악에 시간이 걸린 문제를 Report로 남기는 곳.
짧게 끝나는 건 테스트 이슈 댓글(3줄)로만 남기고, 여기에는 올리지 않음.

# 쓰는 법
1. 테스트 이슈에 담당자(Assignees)를 지정함 → Report의 "담당"
2. 해결하면 [Troubleshooting] TS-번호 페이지를 아래 템플릿으로 만듦
3. 이 목록 표에 한 줄 추가
4. 테스트 이슈에 Report 링크를 댓글로 남기고, 해결 PR에서 Closes #이슈번호

번호는 TS-001부터 순서대로. 제목은 "TS-번호 테스트 이름: 증상 한 줄"
